# Acoustic Levitator — Python Simulation

A physics simulation of a **72-transducer, 40 kHz ultrasonic acoustic levitator**,
modelled on the popular TinyLev open-source design (36 transducers in a concave
top shell + 36 in a concave bottom shell). The code computes the **acoustic
pressure field**, the **Gor'kov radiation potential**, and the **radiation
force** on a levitated particle, and provides **phase-control recipes** to move,
rotate, and shape the trap — including the flower-petal and concentric-ring
group configurations.

This package accompanies the STL model `F9J3WN6JKN8P8KG.stl` of a printed
levitator. The geometry here reproduces the classic TinyLev form factor with
analytical spherical caps (the STL socket positions are not read directly from
the mesh; see *Limitations*).


Or open the notebook:

```bash

```

Minimal example:

```python
import numpy as np
from acoustic_levitator import LevitatorArray, AcousticField, PhaseControl, POLYSTYRENE

mm = 1e-3
lev = LevitatorArray(curvature_radius=0.090, piston_radius=5*mm)
field = AcousticField(lev)
ctrl = PhaseControl(lev)

lev.assign_groups("whole")
lev.set_phase(ctrl.standing_wave(0.0))

X, Y, Z = np.meshgrid(np.linspace(-10*mm, 10*mm, 50),
                      np.linspace(-10*mm, 10*mm, 50),
                      np.linspace(-10*mm, 10*mm, 50), indexing="ij")
U, F = field.gorkov(X, Y, Z, particle=POLYSTYRENE, particle_radius=1*mm)
# trap centre = minimum of U; F = -grad U
```

## Geometry

| Property | Value |
|---|---|
| Transducers | 72 (36 top + 36 bottom) |
| Frequency | 40 kHz |
| Wavelength in air | ≈ 8.57 mm (c₀ = 343 m/s) |
| Shell curvature radius | 0.090 m |
| Piston radius | 5 mm (10 mm diameter, typical TM-2425H13T/R) |
| Concentric rings per shell | 3 — 6 / 12 / 18 elements |
| Ring polar angles | 16°, 32°, 48° |

Each shell is a spherical cap facing the origin. The two caps share the same
focal sphere (a configurable `gap` can separate them). Each transducer's
outward normal points from its socket back toward the origin.

## Theory

### Acoustic field — baffled circular piston

Each transducer is modelled as a baffled circular piston. Its complex pressure
at a field point **r** is

```
p_j(r) = A_j · D(θ_j) · exp(i (k |r − r_j| + φ_j)) / |r − r_j|
D(θ)  = 2 J₁(k a sin θ) / (k a sin θ)
```

with wavenumber `k = 2π/λ`, piston radius `a`, drive phase `φ_j`, and `θ_j`
the angle between the piston axis and the field-point direction. `J₁` is the
first-order Bessel function. The total field is the coherent sum `p = Σ p_j`.

### Gor'kov potential and radiation force

The particle velocity follows from the momentum equation
`v = −∇p / (iωρ₀)`. The time-averaged **Gor'kov potential** of a small
spherical particle is

```
U = V_p [ f₁ ⟨p²⟩ / (2 ρ₀ c₀²)  −  f₂ (3 ρ₀ / 4) ⟨v²⟩ ]

f₁ = 1 − κ_p / κ₀          (compressibility contrast)
f₂ = 2 (ρ_p − ρ₀) / (2 ρ_p + ρ₀)   (density contrast)
```

and the radiation force is `F = −∇U`. For solid particles in air
(`f₁, f₂ ≈ 1`) the trap sits at a **pressure node**, where both `|p|` and
`|v|` are small. The trap stiffness is set by the curvature (Laplacian) of `U`
at the node.

### Phase-control recipes

| Effect | Per-transducer phase `φ_j` | Notes |
|---|---|---|
| Standing wave (levitate) | `sign(z_j) · π/2 + δ` | Two shells driven in anti-phase form nodes spaced `λ/2 ≈ 4.3 mm`. |
| Move up/down | vary `δ` | Top–bottom phase offset translates the nodes axially; a full `2π` shifts one wavelength. |
| Focus (pressure max) | `−k |r_t − r_j|` | Converge all wavefronts on a target point `r_t`. |
| Steer / translate laterally | `−k (d · r_j)` | A linear phase ramp tilts/steers the beam. |
| Rotate (vortex) | `m · atan2(y_j, x_j)` | Phase singularity on the axis carries orbital angular momentum (topological charge `m`); forms a ring trap that spins the particle. `m = ±1` sets spin direction. |

### Group configurations

- **Flower petals** (`assign_groups("petals")`): each shell is split into
  **6 angular sectors of 60°**, each containing **6 transducers** (6 × 6 = 36).
  The implementation sorts each shell's transducers by azimuth and chunks them
  into six consecutive groups of six — robust against floating-point boundary
  flips. This treats each sector as an independent holographic channel for
  lateral steering / tilt and shape control.

- **Concentric rings** (`assign_groups("rings")`): each shell keeps its three
  physical rings — **6 / 12 / 18** transducers (inner / middle / outer).
  Independent per-ring phase tunes axial focus and radial pressure gradients
  (trapping stiffness).

- **Whole** (`assign_groups("whole")`): all 72 transducers form one group.

## API overview

```python
class Transducer      # position, normal, amplitude, phase, group, radius
class LevitatorArray  # builds top/bottom shells; assign_groups / set_phase
class AcousticField   # pressure(), velocity(), gorkov(), force()
class PhaseControl    # standing_wave(), focus(), steer(), vortex(), petal_tilt()
```

`gorkov()` returns the potential `U` and the force array `F = −∇U`. It
accepts both 2-D axial slices (`Y` a constant scalar array) and full 3-D
grids; gradients are computed with central differences. `set_phase` accepts a
scalar, a dict `{group_id: phase}`, or a full per-transducer array.

## Limitations

- **Linear acoustics only** — no acoustic streaming, no multiple scattering,
  no viscous attenuation over the short path, no finite-amplitude effects.
- **Ideal piston model** — real transducers have resonant directivity, coupling
  and absorption that a rigid baffled piston does not capture.
- **Analytical geometry** — socket positions/curvature are taken from the
  analytical spherical cap (TinyLev layout), not read from the STL mesh.
- The Gor'kov expression assumes a small, rigid spherical particle
  (Rayleigh limit); larger or deformable objects need a full scattering model.
